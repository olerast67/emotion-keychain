# Загрузчик платы rev B

Готовый файл `emotion_keychain_revb_bootloader-0.11.0-keychain_s140_6.1.1.hex` — [загрузчик Adafruit nRF52](https://github.com/adafruit/Adafruit_nRF52_Bootloader) 0.11.0 (коммит `c67f0bc`) с небольшим патчем, вместе с SoftDevice S140 6.1.1. Записывается программатором один раз, как описано в [README прошивки](../README.md#первая-прошивка-загрузчик-по-swd). Обычно отдельно его не пишут: он уже есть внутри `keychain-revb-factory.hex` ([готовые файлы](../release/README.md)).

Чем он отличается от загрузчиков готовых плат (`emotion_keychain_revb/board.h`):

- **Кнопка загрузчика** — кнопка брелока P0.22. Загрузчик смотрит на неё только в момент сброса: зажата при USB — ждёт прошивку и показывает диск KEYCHAIN. Сброс с зажатой кнопкой на USB бывает, если держать кнопку дольше 10 с на брелоке, выключенном на зарядке, или если прошивка зависла и её сбросил сторожевой таймер. На работающем брелоке тот же жест — «держать кнопку и подключить USB» — ловит сама прошивка и уходит в загрузчик программным сбросом ([README прошивки](../README.md#загрузчик-и-обновление-по-usb)).
- **Патч `button-dfu-needs-usb.patch`.** Та же кнопка будит брелок из полного сна, а пробуждение — это сброс, и кнопка в этот момент ещё нажата. Без патча загрузчик входил бы в режим прошивки без таймаута, и брелок на батарее висел бы с тёмным экраном. С патчем кнопка действует только при питании от USB. Если компьютер не ответил за 10 с, например брелок на зарядке от розетки, запускается прошивка. Компьютер нашёл диск — загрузчик ждёт, пока USB не отключат, и тогда запускает прошивку.
- **REG0 = 3.3 В** записывается в UICR при первом запуске загрузчика (и сразу перезагрузка): экран и датчики работают уже в загрузчике. В `keychain-revb-factory.hex` это значение уже есть, так что после программатора лишней перезагрузки нет.
- **Не заряжает.** Нижний конец R3 (PROG) — на ножке P0.24 (CHG_EN), а её включает только прошивка, проверив температуру. В загрузчике и на плате без прошивки зарядник выключен; брелок при этом питается от USB.
- **Светодиода нет:** вывод LED — свободная ножка P0.31.
- **Кварц 32 кГц не нужен:** загрузчик Adafruit всегда работает от внутреннего RC.
- **USB VID/PID** взяты у платы Raytac MDBT50Q-RX (из набора Adafruit): загрузчик 239A:010B, прошивка 239A:810B (раздел `[sale]` в `firmware/platformio.ini`; в `boards/keychain_revb.json` — только значения по умолчанию). Для своих прототипов это нормально. Перед продажей нужны свои номера: в загрузчике это `USB_DESC_VID`, `USB_DESC_UF2_PID` и `USB_DESC_CDC_ONLY_PID` в `emotion_keychain_revb/board.h`, потом пересборка по шагам ниже. Плата для этого не меняется.

## Как пересобрать

Нужны `arm-none-eabi-gcc`, `make`, Python и git. Команды запускаются из корня репозитория: первая переходит в папку загрузчика, и дальше все пути — от неё.

USB VID/PID загрузчика (`USB_DESC_VID`, `USB_DESC_UF2_PID`, `USB_DESC_CDC_ONLY_PID` в `emotion_keychain_revb/board.h`) должны совпадать с `usb_vid` и `usb_pid_boot` в разделе `[sale]` файла `firmware/platformio.ini`. Прошивка номера загрузчика не меняет: после правки его пересобирают и пишут программатором.

```sh
cd firmware/bootloader
git clone --recurse-submodules https://github.com/adafruit/Adafruit_nRF52_Bootloader.git
cp -r emotion_keychain_revb Adafruit_nRF52_Bootloader/src/boards/
cd Adafruit_nRF52_Bootloader
git checkout c67f0bc
git submodule update --init --recursive   # подмодули — те, что были у c67f0bc, а не у свежего master
git apply ../button-dfu-needs-usb.patch
make BOARD=emotion_keychain_revb all
# готовый файл: _build/build-emotion_keychain_revb/emotion_keychain_revb_bootloader-*_s140_6.1.1.hex
```

- **Папку `Adafruit_nRF52_Bootloader/` не коммитьте:** это чужой репозиторий, клон нужен только для сборки. После сборки её можно удалить.
- **Новый загрузчик в заводской файл.** `keychain-revb-factory.hex` склеивает `tools/uf2.py` из файла с именем `emotion_keychain_revb_bootloader-0.11.0-keychain_s140_6.1.1.hex` в этой папке (`BOOTLOADER_HEX` в `tools/uf2.py`). Замените его новым файлом под тем же именем. Закоммитьте правки (`board.h`, новый `.hex`, раздел `[sale]`) и поставьте метку (например, `git tag sale-1.0`), иначе версия прошивки будет `-dirty`. Потом пересоберите прошивку: `cd firmware && pio run -e keychain`. Новый `firmware-factory.hex` в `firmware/.pio/build/keychain/` — уже с новым загрузчиком.
- **Брелокам, которые уже прошиты,** новый загрузчик записывают тем же программатором по SWD (J3 на обороте платы), как в [первой прошивке](../README.md#первая-прошивка-загрузчик-по-swd). Стирание перед записью стирает и журнал: рост, знакомые и настройки брелока пропадут.
