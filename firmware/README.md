# Прошивка

Здесь будет прошивка брелока для Seeed XIAO nRF52840 Sense (вариант A). Лицо и характер берутся из [`engine/`](../engine) без изменений. Прошивка отвечает за то, что движок не умеет сам: экран, датчики, питание и сон.

## Что войдёт

| Модуль | Задача |
|---|---|
| `display` | Драйвер SSD1306 по I2C (позже SPI): инициализация, контраст, отправка изменённых окон, выключение экрана, автоопределение SSD1306/SSD1315/SH1106 |
| `imu` | Акселерометр: аппаратные tap, double-tap, wake и ориентация на прерываниях, детект шагов, тряски и падения |
| `mic` | PDM-микрофон кусками: уровень, хлопок, речь, ритм музыки |
| `light` | Датчик света: яркость экрана, темнота в кармане |
| `power` | Заряд батареи, зарядка, отсечка, сохранение состояния |
| `main` | Цикл: события → `Behavior` → `FaceEngine` → экран, сон до `next_update_ms()` |

## Как будет устроен цикл

```cpp
character.update(now);
if (engine.update(now)) send_dirty_windows(engine);
sleep_until(min(engine.next_update_ms(), character.next_update_ms()));
```

Прерывания датчиков будят процессор раньше и превращаются в `character.on_event(...)`.

## Статус

Ждёт железа: этапы 0–4 [плана](../docs/plan.md). Сборка — PlatformIO, ядро Arduino для nRF52. Если замеры покажут, что ядро мешает спать, перейдём на Zephyr / nRF Connect SDK; движок от этого не меняется.
