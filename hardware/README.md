# Платы

Проекты плат в KiCad. Все файлы платы — схема, разводка, Gerber, BOM и CPL — генерируются скриптами из одного описания (у rev B — `rev-b/gen/netlist.py`); руками в KiCad ничего не правится.

| Плата | Что | Статус |
|---|---|---|
| [`rev-b/`](rev-b/README.md) | Своя плата 30 × 46 мм: модуль nRF52840 (Raytac MDBT50Q), зарядник MCP73832 (заряд включает прошивка), датчики, пищалка, вибро, кнопка, USB-C. Стандартный модуль экрана SSD1306 0.96″ по I2C лежит на ушках акриловых рамок корпуса, покупных стоек нет. Корпус — в [`rev-b/case/`](rev-b/case/README.md) | Готова к заказу |
| A | Плата-носитель для XIAO nRF52840 Sense с экраном на стойках M2 | Ранний план, не делался; папки нет |
| C | Следующая ревизия: исправления по первым платам ([план](../docs/plan.md)) | В плане; папки ещё нет |

Как заказать и собрать — в [README платы rev B](rev-b/README.md). Готовая прошивка — в [`firmware/release/`](../firmware/release/README.md). Компоненты, стек и решения — в [docs/hardware.md](../docs/hardware.md).

## Правила для плат

- FR4 1.6 мм, чёрная маска, покрытие ENIG, скруглённые углы.
- Вокруг ушка нет дорожек и открытой меди. Между отверстием и краем платы ≥2.5–3 мм материала.
- У USB-C резисторы 2×5.1 кОм на CC, защита линий от статики и TVS на VBUS.
- Антенна модуля — вне меди, подальше от ячейки и от ушка с кольцом.
- SWD — площадки J3 под кабель Tag-Connect TC2030 на обороте, без разъёма. Они нужны только для первой прошивки, до сборки корпуса; дальше прошивка обновляется по USB.
