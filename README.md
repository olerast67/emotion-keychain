# Брелок с эмоциями

Брелок на сумку или рюкзак с маленьким OLED-экраном, на котором живёт мордочка. Она моргает, оглядывается, удивляется, смеётся и меняет выражение сама или в ответ на то, что происходит вокруг.

Референс: ролик nekoto.in «Product 1 is going to launch soon» (скриншоты ниже).

## Что видно на референсе

- Экран: монохромный OLED 0,96" 128×64 на синей плате с 4 пинами (GND, VCC, SCL, SDA), то есть модуль SSD1306 по I2C. Свечение голубое.
- Сзади под экраном стоит вторая плата с электроникой и, судя по толщине, аккумулятором. Сбоку видна кнопка или разъём.
- Сверху ушко под кольцо, брелок висит на карабине.
- Эмоции на скриншотах: спокойный взгляд с глазами-кольцами и ротиком-чёрточкой, удивление с бровями и ротиком «о», смех с глазами `> <` и румянцем, «слушаю» со звуковыми волнами у глаз.

## Движок лиц

![Эмоции в движении](docs/img/highlights.gif)

139 анимированных эмоций, от базовых до мемных, плавные переходы и характер, который сам реагирует на ситуации: тапы, тряску, падения, звук, свет, тепло и зарядку. Код один на всех: прошивка nRF52840, симуляторы на ПК и страница в браузере.

- [Как устроен движок](docs/engine.md): параметры лица, переходы, жесты, экономия энергии, поведение.
- [Каталог эмоций](docs/emotions.md): все 139 с описанием, когда каждая появляется.

## Структура

```
engine/       движок лиц: C++20 без кучи и libm, тесты в engine/tests
sim/cli/      facegen — GIF, контактные листы, бенчмарк, каталог
sim/sdl/      facesim — оконный симулятор на SDL2
sim/web/      симулятор в браузере (движок в WebAssembly)
tools/        вспомогательные скрипты
docs/         план, описание движка, каталог эмоций
reports/, research_notes/   исследования
```

## Сборка и запуск

Нужны CMake 3.16+, компилятор с C++20 (GCC 10+ или Clang 12+). SDL2 нужен только для оконного симулятора.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/face_tests                                    # тесты движка
./build/facegen list                                  # все эмоции и клипы
./build/facegen anim lenny out/lenny.gif              # анимация эмоции в GIF
./build/facegen trans neutral laugh out/t.gif         # переход между эмоциями
./build/facegen sheet out/all.gif --scale 2           # контактный лист всех эмоций
./build/facegen bench                                 # нагрузка на экран и шину по каждой эмоции
./build/facesim                                       # окно (если найден SDL2)
```

Веб-симулятор (нужны `clang` с целью wasm32 и `wasm-ld` из пакета `lld`):

```sh
sim/web/build.sh        # → sim/web/dist/index.html, открывается в браузере без сервера
```
