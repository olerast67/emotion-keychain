ESP32 stand flasher

Flashes the Emotion keychain test stand: any supported ESP32 board plus a 0.96″ SSD1306 I2C screen shows all the emotions of the keychain face engine. Nothing to install: it works right in the browser.

Flash

This browser cannot talk to USB devices. Use desktop Chrome or Edge.

Flashing only works over HTTPS or on localhost.

The board type is detected automatically and the matching firmware is written from address 0x0.

How it works

  1. Wire the screen (and, optionally, a TTP223 touch button and a passive buzzer) as shown below.
  2. Plug the board in with a USB data cable (charge-only cables will not work).
  3. Press “Connect and flash”, pick the board's serial port and confirm.
  4. When it is done, open “Logs & Console” in the same dialog (115200 baud) to see messages and type commands.

If the port does not appear, hold BOOT while plugging the board in. ESP32-C5-DevKitC-1: use the USB-C port labelled UART.
