# План разработки

## Принципы

- **Лицо на экране всегда.** Экран гаснет, только когда его никто не может видеть: в кармане, в сумке, в темноте.
- **Свой движок лиц** — `engine/`, без чужого кода лиц и чужих анимаций.
- **Прозрачный корпус.** Акриловый «бутерброд»: платы видно насквозь, ячейка закрыта со всех сторон ([железо](hardware.md), [корпус](../hardware/rev-b/case/README.md)).
- **Сразу своя плата rev B.** Плату-носитель для XIAO (вариант A) не делали: прошивку rev B целиком проверяет [симуляция платы](../firmware/README.md#симуляция-платы-целиком), а лица на живой панели — стенд на ESP32.

### 1. Движок и симулятор — готово

- [x] Кадровый буфер в формате SSD1306, поиск изменённых окон.
- [x] Растеризатор: кольца, скруглённые прямоугольники, эллипсы, толстые линии и дуги, многоугольники, значки.
- [x] Параметрическое лицо: глаза, веки, брови, 12 видов рта.
- [x] Плавные переходы; смена формы прячется за морганием.
- [x] Моргание, саккады, дрейф против выгорания, фирменный жест у каждой эмоции.
- [x] 139 эмоций в 10 категориях, 38 значков, 17 клипов.
- [x] Поведение: события датчиков → реакции из пулов, настроение, суточный ритм, фоновые занятия.
- [x] Экономия: пропуск отрисовки по хэшу, свой период кадров у каждого движения.
- [x] Симуляторы: `facegen`, `facesim` (SDL2), веб-версия (WebAssembly).
- [x] Тесты (1000+ проверок) и CI.

### 1b. Характер и сюрпризы — готово в движке и в прошивке платы

- [x] Свой характер из серийного номера: 10 архетипов, особенности внешности, 10 % редких, 1 % легендарных с кибер-глазом.
- [x] Рост: 44 эмоции на старте, 11 имплантов за опыт (дни, касания, шаги, встречи, дуэли), всё за ~месяц.
- [x] Сохранение роста во флеше с контрольной суммой.
- [x] Сцены: загрузка OLERAST LINK, взлом, дождь данных, ERROR 404, перезагрузка, прятки, апгрейд, Новый год, день рождения, Хэллоуин, встреча, дуэль, секретный разговор.
- [x] Сюрпризы раз в 1–2,5 дня, праздники раз за дату.
- [x] Киберпанк-тема: прицел по поводу (цепкие эмоции, сканирование, встреча), редкие сбои сигнала.
- [x] Зрачки скатываются при наклоне, рывок — взгляд в сторону движения.
- [x] Встречи по BLE на nRF52840 — [протокол](encounters.md); в симуляции две платы и эфир между ними. На живых платах — этап 2.
- [x] Наклон, тряска и шаги от акселерометра в прошивке платы; пороги — на живой плате (этап 4).
- [x] Голос: реплики пищалкой со своей манерой у каждого характера, музыка сцен, тихие часы, секретный разговор шифром после дуэли ([голос брелока](sound.md)).
- [x] Серия дней и 24 достижения, NEW у открытой эмоции, прогресс версии 3 с переносом старых записей.
- [x] Дружба брелоков по дням встреч, подарок старшего, шёпот старых знакомых, общие сцены в начале очереди.
- [x] Батарея: сцена зарядки с процентом, экорежим, опыт за заботу, выключение.
- [x] Ретро-тема; пасхалки по дате и времени, секретный стук (на стенде и в симуляторе; на плате rev B пока нет — этап 4), синий экран, визор, заставка на зарядке.
- [x] Вибро на встречи и дуэли.

### 0. Закупка и стенд

- [x] Прошивка стенда для ESP32-C5, ESP32, C3 и S3 + SSD1306 и сенсорной кнопки: живой режим, показ каталога, команды по Serial ([firmware/](../firmware/README.md)).
- [x] Собрать стенд на ESP32-C5 и пройти [чек-лист живой панели](../firmware/README.md#что-проверить-на-живой-панели): эмоции читаются; исправлены близость к краю и тонкие линии.

- [ ] Измерить модули экрана разных продавцов: размеры, отверстия, высота деталей на обороте, контроллер, распиновка, LDO.
- [ ] Смерить ячейки 402025, 502025 и 602025 из партии: толщина, ширина, длина, выход проводов.

### 2. Живой прототип — на плате rev B

- [ ] Драйвер SSD1306 по I2C:
  - [x] инициализация, контраст, отправка окон, выключение экрана, SH1106 в драйвере, поиск адреса 0x3C/0x3D;
  - [ ] VCOMH и precharge по замерам;
  - [ ] автоопределение SSD1306, SSD1315 или SH1106.
- [x] Движок в прошивке платы (`firmware/src/keychain`), кадры сверяются с экраном в симуляции.
- [ ] Первая плата по списку [«Что проверить»](../firmware/README.md#что-проверить-на-первой-плате): питание, загрузчик, экран, оси акселерометра, касания, звук, заряд, встреча, выключение.
- [ ] Измерить время рендера и передачи кадра на nRF52840.
- [ ] Замеры PPK2:
  - лицо на разных контрастах;
  - статичный кадр и анимация;
  - карман с выключенным экраном (оценка 0.13 мА);
  - выключенный брелок (предел 25 мкА).
- [ ] Заменить оценки в [энергобюджете](power.md) замерами.

### 3. Энергетика постоянного лица

- [x] Сон между кадрами, кадры только при изменении лица.
- [x] Датчик света: адаптивная яркость, темнота с гистерезисом, экран обесточен в кармане.
- [x] Ток по режимам в симуляции платы: лицо ~2.7 мА, приглушённое ~0.9 мА, карман ~0.13 мА ([энергобюджет](power.md)).
- [x] Ядро для rev B — Arduino от Adafruit с SoftDevice S140.
- [ ] Микрофон окнами, контраст по люксам, I2C со сном ядра, цикл по событиям — список в [энергобюджете](power.md).
- [ ] Эксперименты с контрастом, VCOMH, precharge и ретро-режимом на живой панели.
- [ ] Тест разряда ячеек S, M, L: «16 ч лицо + 8 ч темнота».

### 4. Датчики и поведение на железе

- [x] Акселерометр в прошивке: аппаратные тап и двойной тап, тряска, падение, переворот, шаги; толчки своего мотора не дают событий.
- [x] Микрофон: хлопок, речь, музыка; свои пищалку и мотор микрофон не слышит.
- [x] Зарядка и уровень батареи: сцена, экорежим, выключение до отсечки, заряд только при 10–42 °C по кристаллу nRF.
- [ ] Записать данные с рюкзака (`v on`): ходьба, бег, лестница, транспорт. Подобрать пороги, отсечь ложные тапы.
- [ ] Проверить, слышат ли акселерометр и микрофон мотор и пищалку через корпус.
- [ ] Медленный двойной тап на живой плате: окно одиночного тапа в прошивке 0.5 с, а у LIS3DH окно двойного ~0.72 с. Второй тап позже ~0.4 с может дать и тап, и двойной тап. Сначала замер, потом правка `TIME_WINDOW` или окна в прошивке.
- [ ] Секретный стук на плате rev B: сейчас не срабатывает, и достижение KNOCK KNOCK не получить (на брелоке 23 из 24). Одиночный тап приходит в движок только после 0.5 с ожидания двойного, а «тук-тук» датчик сам сливает в двойной тап. Нужно отдавать движку время каждого клика датчика, по замерам на живой плате, и сценарий стука в симуляции платы.
- [ ] Симуляция: детектор касаний по выборкам вместо флага из сценария и связь «мотор → акселерометр» по замеру на живой плате.
- [ ] День носки: счётчик ложных тапов, «не надоедает ли».

### 5. Эмоции на живой панели

- [ ] Контактный лист на панели с 30–50 см и с расстояния брелока на сумке.
- [ ] Поправить мелкие значки, которые не читаются на 0.96″.
- [ ] Сравнить похожие пары: страх и удивление, грусть и усталость, злость и раздражение.

### 8. Вариант B: своя плата

**Rev B — готова к заказу** (`hardware/rev-b`, 30 × 46 мм и ушко, 4 слоя):

- [x] Схема: модуль MDBT50Q (nRF52840), зарядка MCP73832 с разрешением от прошивки, разделение питания USB и батареи, LIS3DH, LTR-303ALS, микрофон PDM, пищалка и вибромотор на ключах, USB-C с CC-резисторами, TVS и ESD, площадки Tag-Connect для SWD, ключ питания экрана.
- [x] Разводка: земля L2, шины питания и медленные сигналы в L3, антенна у края без меди; DRC — 0 ошибок, 0 несоединённых, 0 предупреждений.
- [x] Gerber, BOM и CPL для JLCPCB, BOM и расстановка для PCBWay, сборочные чертежи, список ручной сборки; панель для монтажа из 2 плат (`hardware/rev-b/out/panel`).
- [x] Исправления по предрелизному аудиту: SA0 акселерометра на VDD, ёмкость REG0, перемычки экрана, заряд по температуре, уровни статуса заряда, защита VBUS ([README платы](../hardware/rev-b/README.md#проверка-перед-заказом)).
- [x] Прошивка платы: все датчики, голос, вибро, встречи по BLE, сон и выключение, журнал во флеше, загрузчик с диском UF2, заводской файл с загрузчиком и UICR (`firmware/src/keychain`, `firmware/bootloader`).
- [ ] Заказ у JLCPCB: PCB — 5 панелей (меньше не заказать), из них со сборкой 3 = 6 плат (PCBA — от 2 панелей); панель 76 × 72 мм, 2 платы, из `hardware/rev-b/out/panel` ([панель](../hardware/rev-b/README.md#панель-для-монтажа), [заказ](../hardware/rev-b/README.md#заказ-на-jlcpcb)). Номер заказа — «Order Number (Specify Position)»: он ляжет на метку под ячейкой. Руками — модуль экрана, ячейка, вибромотор.
- [ ] Ввод в эксплуатацию на живой плате: список проверок в [README платы](../hardware/rev-b/README.md#первое-включение) и [прошивки](../firmware/README.md#что-проверить-на-первой-плате).
- [ ] Замеры: выключенный ≤25 мкА, карман ~0.13 мА, лицо ≤2.7 мА; тест разряда.
- [ ] Горячее подключение USB: осциллограф на VBUS и VSYS, короткий кабель, 10 подключений ([как](../hardware/rev-b/README.md#на-первых-платах)). По модели ngspice звон на короткое время выше предела модуля 5.8 В; TVS D3 его не гасит. Записать пик и время выше 5.8 В — это данные для демпфера rev C. Для своих прототипов rev B риск принят; перед продажей замер обязателен, критерий и что делать, если не прошёл, — в [README платы](../hardware/rev-b/README.md#на-первых-платах).
- [ ] Датчик температуры для заряда: брелок час в холодильнике (+4…6 °C), сразу USB — `sensors` показывает температуру в пределах 2 °C от кухонного термометра рядом. Из морозилки — консоль пишет «Заряд не идёт», светодиод ярко не горит. Повторять на нескольких брелоках из каждой партии.
- [ ] Радио в корпусе: дальность встреч двумя брелоками, порог −70 дБм ([встречи](encounters.md)).

**Перед продажей rev B** — только если брелоки когда-нибудь пойдут в продажу; для подарков не нужно:

- [x] Пакет встреч без Company ID: свой бесплатный UUID в данных сервиса ([пакет](encounters.md#рекламный-пакет)).
- [ ] Свои USB VID/PID вместо номеров Adafruit — в разделе `[sale]` файла `firmware/platformio.ini`, загрузчик пересобрать. Сборка — с меткой, без `-dirty`. Файлы `firmware/release/` — только для прототипов ([загрузчик](../firmware/bootloader/README.md#как-пересобрать), [пакет встреч](encounters.md#рекламный-пакет)).
- [ ] Паспорт ячейки (ток заряда от 100 мА) и проверка модулей экрана на стенде ([что сверить](../hardware/rev-b/README.md#что-сверить-перед-заказом)).
- [ ] Испытания до первой продажи: звон USB ([замер](../hardware/rev-b/README.md#на-первых-платах)) и пилотная партия (ниже). Для подарков — по желанию; самое полезное и бесплатное — поносить один брелок неделю-две, прежде чем дарить остальные.

  **Пилотная партия** — например, 5 брелоков, хотя бы по одному каждой версии, которую будете продавать:
  
  | Испытание | Как | Годится, если |
  |---|---|---|
  | Падение | с 1–1.5 м на плитку, на каждую грань, всего 10 раз | корпус не треснул у винтов и ушка, ячейку не видно, лицо и кнопка работают |
  | Рывок за ушко | груз или безмен 5–10 кг на кольце | у отверстия ушка нет трещин |
  | Заряд на холоде | час в холодильнике (+4…6 °C), сразу USB и `sensors`; потом то же из морозилки | температура в `sensors` — в пределах 2 °C от термометра рядом; из морозилки консоль пишет «Заряд не идёт», светодиод ярко не горит |
  | Пустая ячейка | разрядить до конца | брелок сам показывает LOW BATTERY и GOODNIGHT и гаснет; нажатие кнопки на миг показывает пустую батарею; после зарядки работает |
  | Ток | PPK2 ([как мерить](power.md#как-мерить)) | выключенный — меньше 25 мкА, карман — не больше 0.3 мА, лицо на свету — не больше 2.7 мА |
  | Время работы | полная ячейка, 16 ч лица на свету и 8 ч темноты в сутки, до выключения | записать дни у каждой версии; в памятке и объявлениях — эти дни вместо расчёта |
  | Циклы заряда | 50 циклов: полный заряд, потом разряд до выключения с лицом на свету (у S около 2 суток на цикл). Это месяцы — начните на первом же собранном брелоке | ячейка не вздулась, крышка и дно не отходят, время работы заметно не упало |
  | Неделя носки | на рюкзаке, с ключами | нет трещин, кнопка не нажимается сама, лицо без полос |

- [x] Памятка владельцу — [user-guide.md](user-guide.md).
- [ ] Памятка в коробку: напечатать [карточку](user-guide.md#карточка-в-коробку).
- [ ] Каждый брелок перед отправкой — проверки из [первого включения](../hardware/rev-b/README.md#первое-включение), последним `factory yes` ([консоль](../firmware/README.md#консоль)).

**Rev C — полностью заводская сборка.** Rev B остаётся рабочим вариантом, rev C делается рядом в `hardware/rev-c`:

- [ ] Экран без своей платы: голое стекло SSD1306 со шлейфом и разъём FPC, который поставит JLCPCB; экран вставляется в разъём. Обвязка контроллера (конденсаторы накачки, VCOMH, IREF) — на нашей плате.
- [ ] Разъём под аккумулятор с ключом полярности (JST или аналог): ячейка подключается штекером, без пайки и без риска перевернуть. Нужен и для ЕС: с 18.02.2027 покупатель должен сам менять ячейку обычными инструментами (Регламент (EU) 2023/1542, статья 11). Ячейка должна сниматься без снятия экрана — тут помогает экран на разъёме FPC.
- [ ] Защита от переполюсовки ячейки: P-MOSFET или идеальный диод в VBAT. Сейчас от перевёрнутой ячейки спасает только её плата защиты.
- [ ] Температура ячейки: NTC под ячейкой и зарядник со входом термистора (TS) вместо разрешения заряда по температуре кристалла nRF.
- [ ] Вибромотор: найти у JLCPCB/LCSC модель для поверхностного монтажа; если нет — площадки под провода остаются.
- [ ] Лапки корпуса USB-C — вне контура ячейки: сейчас их пайка выходит на лицевую сторону прямо под ячейку.
- [ ] Метки полярности ячейки крупнее, с «+ VBAT / − GND, красный = +», и на обороте тоже.
- [ ] D1 с малой утечкой в жару: нагретый диод чуть поднимает VBUS без USB. Прошивка rev B этого не проверяет и считает USB по одному VBUSDETECT. Ложный «USB» возможен только у сильно нагретого D1 и сам пропадает при VBAT ≈ 3.35 В; хуже всего — позднее выключение на пустой ячейке. При желании в прошивке: в `poll_battery` считать USB только при VDDH ≥ 3.8 В.
- [ ] Демпфер на VBUS у разъёма J1: RC-цепочка или конденсатор с потерями (~0.5–1 Ом последовательно, ≥10 мкФ). При горячем подключении коротким кабелем VBUS и VSYS по модели ngspice звенят выше предела модуля 5.8 В (VBUS и VDDH), а TVS D3 — ограничитель импульсов с пробоем 6.4–7.1 В, звон он не гасит. Одних 10 Ом перед выводом VBUS модуля мало: VDDH (он же VSYS) и зарядник они не защищают. Схему проверить в ngspice и положить в репозиторий.
- [ ] Статус заряда CHG_IO: «1» подтягивать к VDD, а не от VBUS через светодиод. Тогда уровень верен и на плате без прошивки (VDD 1.8 В), и при слабом USB ниже 4.6 В.
- [ ] 100–330 Ом последовательно в SWDIO и SWDCLK: до первой прошивки плата работает при 1.8 В, а программатор с постоянными 3.3 В гонит ток через защитные диоды выводов.
- [ ] Запретная зона антенны ниже вдоль правого края (до y ≈ 16 мм): в rev B там единственный путь сигналов от модуля к SWD и кнопке.
- [ ] Полосы без деталей вдоль двух противоположных краёв платы — под технологические поля или перемычки панели. В rev B перемычки на левом и верхнем краях и одна короткая на нижнем, между USB-C и правым винтом. На правом крае (кнопка и модуль с антенной) их нет.
- [ ] Кнопку SW1 сдвинуть наружу на 0.35–0.4 мм (или вырезать край платы у кнопки): сейчас шток выходит за край всего на 0.17 мм при ходе 0.2 мм, и толкателю нужны крылья под платой.
- [ ] Запас под толстые вилки USB-C: в rev B нижняя рамка ячейки лежит прямо над вилкой (вилка 6.5 мм по пределу стандарта касается её на 0.02 мм). В rev C — гнездо ниже или торец ячейки дальше от него, не меньше 1.5 мм акрила между окном вилки и ячейкой.
- [ ] Выход звука пищалки вбок: сейчас она звучит в дно через отверстие Ø3 мм, и на спине или в сумке брелок тише.
- [ ] Перерасстановка и разводка тем же конвейером (`build.py place --force`, `route`, `fab`), DRC 0/0/0. `place` без `--force` разведённую плату не затрёт: с ним плата остаётся без дорожек до `route`. Правило 0.5 мм между отверстиями разных цепей — уже в DRC (`keychain-rev-b.kicad_dru`), его оставить.
- [ ] Новый корпус под тоньше стек: без модуля экрана и стопки рамок под ним.
- [ ] Ячейка 20 × 30 мм (402030–602030), если плата под ней вырастет: цель «16 ч лица ≥5 дней» сейчас выполняется только в версии L ([энергобюджет](power.md)).
- [ ] Ключ экрана: R7 и R9 — 1 МОм вместо 100 кОм (−60 мкА при включённом экране, плавный старт остаётся).
- [ ] Кварц 32 кГц: точнее часы и −1–2 мкА.

### 9. Надёжность и полировка

- [ ] 4 недели лица 24/7, затем осмотр на белом экране.
- [ ] 50+ циклов заряда, поведение на низком заряде, заряд в холоде и жаре на живой плате.
- [x] Сторожевой таймер, восстановление I2C, защита данных во flash (журнал, тест с обрывами питания).
- [x] Обновление прошивки по USB: загрузчик UF2, вход в него кнопкой при подключении USB; зависшую прошивку сбрасывает сторожевой таймер, и загрузчик снова видит кнопку.

## Решения

1. **Темнота:** экран обесточивается через минуту темноты; ночью при свете — приглушённое лицо (ночь — только по заданному времени: часов с батарейкой нет).
2. **Ячейка:** три версии корпуса — 402025, 502025, 602025.
3. **Bluetooth:** встречи брелоков без соединения ([протокол](encounters.md)); реклама и короткое прослушивание добавляют немного к среднему току. Обновления — по USB.
4. **Задняя сторона:** прозрачное дно корпуса, плату видно.
5. **Заряд:** только с разрешения прошивки и при 10–42 °C по температуре кристалла (начало с 10 °C, остановка ниже 7 °C и выше 45 °C); в rev C — NTC.
