# План разработки

## Принципы

- **Лицо на экране всегда.** Экран гаснет, только когда его никто не может видеть: в кармане, в сумке, в темноте.
- **Свой движок лиц** — `engine/`, без чужого кода лиц и чужих анимаций.
- **Прозрачный корпус.** Акриловый «бутерброд»: платы видно насквозь, ячейка закрыта со всех сторон ([железо](hardware.md), [корпус](../hardware/rev-b/case/README.md)).
- **Сразу своя плата rev B.** Плату-носитель для XIAO (вариант A) не делали: прошивку rev B целиком проверяет [симуляция платы](../firmware/README.md#симуляция-платы-целиком), а лица на живой панели — стенд на ESP32.

### 1. Движок и симулятор — готово

- [x] Кадровый буфер в формате SSD1306, поиск изменённых окон.
- [x] Растеризатор: кольца, скруглённые прямоугольники, эллипсы, толстые линии и дуги, многоугольники, значки.
- [x] Параметрическое лицо: глаза, веки, брови, 12 видов рта.
- [x] Плавные переходы; смена формы прячется за морганием.
- [x] Моргание, саккады, дрейф против выгорания, фирменный жест у каждой эмоции.
- [x] 139 эмоций в 10 категориях, 38 значков, 17 клипов.
- [x] Поведение: события датчиков → реакции из пулов, настроение, суточный ритм, фоновые занятия.
- [x] Экономия: пропуск отрисовки по хэшу, свой период кадров у каждого движения.
- [x] Симуляторы: `facegen`, `facesim` (SDL2), веб-версия (WebAssembly).
- [x] Тесты (1000+ проверок) и CI.

### 1b. Характер и сюрпризы — готово в движке и в прошивке платы

- [x] Встречи по BLE на nRF52840 — [протокол](encounters.md); в симуляции две платы и эфир между ними. На живых платах — этап 2.
- [x] Наклон, тряска и шаги от акселерометра в прошивке платы; пороги — на живой плате (этап 4).
- [x] Голос: реплики пищалкой со своей манерой у каждого характера, музыка сцен, тихие часы, секретный разговор шифром после дуэли ([голос брелока](sound.md)).

### 8. Вариант B: своя плата

**Rev B — готова к заказу** (`hardware/rev-b`, 30 × 46 мм и ушко, 4 слоя):

- [x] Схема: модуль MDBT50Q (nRF52840), зарядка MCP73832 с разрешением от прошивки, разделение питания USB и батареи, LIS3DH, LTR-303ALS, микрофон PDM, пищалка и вибромотор на ключах, USB-C с CC-резисторами, TVS и ESD, площадки Tag-Connect для SWD, ключ питания экрана.
- [x] Разводка: земля L2, шины питания и медленные сигналы в L3, антенна у края без меди; DRC — 0 ошибок, 0 несоединённых.
- [x] Gerber, BOM и CPL для JLCPCB, BOM и расстановка для PCBWay, сборочные чертежи, список ручной сборки.
- [x] Исправления по предрелизному аудиту: SA0 акселерометра на VDD, ёмкость REG0, перемычки экрана, заряд по температуре, уровни статуса заряда, защита VBUS ([README платы](../hardware/rev-b/README.md#проверка-перед-заказом)).
- [x] Прошивка платы: все датчики, голос, вибро, встречи по BLE, сон и выключение, журнал во флеше, загрузчик с диском UF2, заводской файл с загрузчиком и UICR (`firmware/src/keychain`, `firmware/bootloader`).
- [ ] Заказ 5 плат со сборкой; руками — модуль экрана, ячейка, вибромотор.
- [ ] Ввод в эксплуатацию на живой плате: список проверок в [README платы](../hardware/rev-b/README.md#первое-включение) и [прошивки](../firmware/README.md#что-проверить-на-первой-плате).
- [ ] Замеры: выключенный ≤25 мкА, карман ~0.13 мА, лицо ≤2.7 мА; тест разряда.
- [ ] Радио в корпусе: дальность встреч двумя брелоками, порог −70 дБм ([встречи](encounters.md)).

**Rev C — полностью заводская сборка.** Rev B остаётся рабочим вариантом, rev C делается рядом в `hardware/rev-c`:

- [ ] Экран без своей платы: голое стекло SSD1306 со шлейфом и разъём FPC, который поставит JLCPCB; экран вставляется в разъём. Обвязка контроллера (конденсаторы накачки, VCOMH, IREF) — на нашей плате.
- [ ] Разъём под аккумулятор с ключом полярности (JST или аналог): ячейка подключается штекером, без пайки и без риска перевернуть.
- [ ] Защита от переполюсовки ячейки: P-MOSFET или идеальный диод в VBAT. Сейчас от перевёрнутой ячейки спасает только её плата защиты.
- [ ] Температура ячейки: NTC под ячейкой и зарядник со входом термистора (TS) вместо разрешения заряда по температуре кристалла nRF.
- [ ] Свои USB VID/PID вместо номеров Adafruit — обязательно перед продажей ([README прошивки](../firmware/README.md#загрузчик-и-обновление-по-usb)).
- [ ] Вибромотор: найти у JLCPCB/LCSC модель для поверхностного монтажа; если нет — площадки под провода остаются.
- [ ] Лапки корпуса USB-C — вне контура ячейки: сейчас их пайка выходит на лицевую сторону прямо под ячейку.
- [ ] Метки полярности ячейки крупнее, с «+ VBAT / − GND, красный = +», и на обороте тоже.
- [ ] D1 с малой утечкой в жару: нагретый диод чуть поднимает VBUS без USB. До тех пор прошивке стоит считать USB подключённым, только если ещё и VDDH ≥ 4 В.
- [ ] 10 Ом последовательно с выводом VBUS модуля: с C8 это фильтр ~1 мкс. При горячем подключении на VBUS бывает до 6.1–6.4 В на доли микросекунды, а предел вывода — 5.8 В; TVS начинает проводить только с 6.4 В.
- [ ] 100–330 Ом последовательно в SWDIO и SWDCLK: до первой прошивки плата работает при 1.8 В, а программатор с постоянными 3.3 В гонит ток через защитные диоды выводов.
- [ ] Запретная зона антенны ниже вдоль правого края (до y ≈ 16 мм): в rev B там единственный путь сигналов от модуля к SWD и кнопке.
- [ ] Перерасстановка и разводка тем же конвейером (`build.py place/route/fab`), DRC 0/0.
- [ ] Новый корпус под тоньше стек: без модуля экрана и проставок.
- [ ] Ячейка 20 × 30 мм (402030–602030), если плата под ней вырастет: цель «16 ч лица ≥5 дней» сейчас выполняется только в версии L ([энергобюджет](power.md)).
- [ ] Ключ экрана: R7 и R9 — 1 МОм вместо 100 кОм (−60 мкА при включённом экране, плавный старт остаётся).
- [ ] Кварц 32 кГц: точнее часы и −1–2 мкА.

## Риски

| Риск | Признак | Что делаем | Когда проверяем |
|---|---|---|---|
| Автономность ниже цели | Лицо выше 2.7 мА, карман выше 0.3 мА | Микрофон окнами, контраст по люксам, ячейка L | Этапы 2–3 |
| Ток выключенного брелока | Больше 25 мкА | Искать утечку: SA0, D1 и R6, ключ экрана | Этап 2 |
| Выгорание экрана | Следы на белом экране | Дрейф, жесты, контраст ≤0x7F | Этап 9 |
| Ложные тапы при ходьбе | Реакции без причины | Аппаратный тап с окнами, записи с рюкзака | Этап 4 |
| Разброс модулей «SSD1306» | Сдвиг, мусор, не включается | Несколько продавцов, перемычки порядка питания, автоопределение контроллера | Этапы 0–2 |
| Ячейка толще номинала | Модуль экрана не ложится на ушки рамок | Смерить партию, версия корпуса на ступень выше | Этап 0 |
| Перемычка припоем у штырей экрана | Короткое на питании экрана | Прозвонка до включения, перемычки отодвинуты | Этап 2 |
| Хрупкий шлейф экрана | Полосы после ударов | Каптон и UV-клей, затем вариант C | Этап 7 |
| Повреждение ячейки | Вздутие, проколы | Ячейка между платами в рамке, плата защиты, отсечка, заряд только в тепле | Этап 7 |
| Лицо не видно на солнце | Не читается на улице | Максимальный контраст в ярком свете | Этап 7 |
| Ушко ломается | Трещины у отверстия | FR4 1.6 мм, запас материала, тест рывком | Этап 7 |
| Радио в корпусе хуже | Встречи только вплотную | Нейлоновые винты, порог RSSI по замерам | Этап 2 |

## Решения

1. **Темнота:** экран обесточивается через минуту темноты; ночью при свете — приглушённое лицо.
2. **Ячейка:** три версии корпуса — 402025, 502025, 602025.
3. **Bluetooth:** встречи брелоков без соединения ([протокол](encounters.md)); реклама и короткое прослушивание добавляют немного к среднему току. Обновления — по USB.
4. **Задняя сторона:** прозрачное дно корпуса, плату видно.
5. **Заряд:** только с разрешения прошивки и при 3–42 °C по температуре кристалла; в rev C — NTC.
