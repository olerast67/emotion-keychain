# План разработки

## Принципы

- **Лицо на экране всегда.** Экран гаснет, только когда его никто не может видеть: в кармане, в сумке, ночью в темноте.
- **Свой движок лиц** — `engine/`, без чужого кода лиц и чужих анимаций.
- **Корпуса нет.** Конструкция из открытых плат, прочная и безопасная для аккумулятора, см. [железо](hardware.md).
- **Сначала вариант A** (XIAO nRF52840 Sense + белый SSD1306), своя плата — после первых продаж.

### 1. Движок и симулятор — готово

- [x] Кадровый буфер в формате SSD1306, поиск изменённых окон.
- [x] Растеризатор: кольца, скруглённые прямоугольники, эллипсы, толстые линии и дуги, многоугольники, значки.
- [x] Параметрическое лицо: глаза, веки, брови, 12 видов рта.
- [x] Плавные переходы; смена формы прячется за морганием.
- [x] Моргание, саккады, дрейф против выгорания, фирменный жест у каждой эмоции.
- [x] 139 эмоций в 10 категориях, 38 значков, 17 клипов.
- [x] Поведение: события датчиков → реакции из пулов, настроение, суточный ритм, фоновые занятия.
- [x] Экономия: пропуск отрисовки по хэшу, свой период кадров у каждого движения.
- [x] Симуляторы: `facegen`, `facesim` (SDL2), веб-версия (WebAssembly).
- [x] Тесты (1000+ проверок) и CI.

### 0. Закупка и стенд

- [ ] Закупить по [списку](hardware.md#закупки-для-старта).
- [ ] Стенд: XIAO + модуль на макетке, питание от PPK2 вместо ячейки.
- [ ] Измерить модули разных продавцов: размеры, отверстия, контроллер, распиновка.

### 2. Живой прототип

- [ ] Драйвер SSD1306 по I2C:
  - инициализация, контраст, VCOMH, precharge;
  - отправка окон, выключение экрана;
  - автоопределение SSD1306, SSD1315 или SH1106.
- [ ] Перенести движок в `firmware/`, проверить читаемость на живой панели.
- [ ] Измерить время рендера и передачи кадра на nRF52840.
- [ ] Замеры PPK2:
  - чёрный, но включённый экран;
  - лицо на разных контрастах;
  - статичный кадр и анимация;
  - экран выключен;
  - сон XIAO.
- [ ] Заменить расчёты в [энергобюджете](power.md) замерами.

### 3. Энергетика постоянного лица

- [ ] Сон между кадрами по таймеру и прерываниям.
- [ ] Эксперименты с контрастом, VCOMH, precharge и ретро-режимом.
- [ ] Датчик света: адаптивная яркость, детект темноты с гистерезисом, состояние DARK.
- [ ] Разобраться со сном XIAO, если он берёт сотни микроампер.
- [ ] Тест разряда: ячейка 250–300 мА·ч, «16 ч лицо + 8 ч темнота».
- [ ] Остаёмся на Arduino-ядре или переходим на Zephyr / nRF Connect SDK.

### 4. Датчики и поведение на железе

- [ ] Акселерометр: аппаратные tap, double-tap, wake и ориентация на прерываниях.
- [ ] Записать данные с рюкзака: ходьба, бег, лестница, транспорт. Подобрать пороги, отсечь ложные тапы.
- [ ] Микрофон: работа кусками, уровень, хлопок, речь, ритм музыки.
- [ ] Зарядка и уровень батареи: лица «кушает» и «голоден», сохранение состояния, отсечка.
- [ ] День носки: счётчик ложных тапов, «не надоедает ли».

### 5. Эмоции на живой панели

- [ ] Контактный лист на панели с 30–50 см и с расстояния брелока на сумке.
- [ ] Поправить мелкие значки, которые не читаются на 0.96″.
- [ ] Сравнить похожие пары: страх и удивление, грусть и усталость, злость и раздражение.

### 6. Вариант A: плата-носитель XIAO

- [ ] KiCad, задняя плата:
  - контур модуля плюс ушко;
  - отверстия совпадают с модулем;
  - посадочное место XIAO;
  - площадки ячейки, кнопка, датчик света.
- [ ] Заказать 5–10 плат: чёрная маска, ENIG, 1.6 мм.
- [ ] Сборка, крепление ячейки, защита шлейфа.
- [ ] Неделя носки на рюкзаке.

### 7. Механика открытых плат

- [ ] Падение с 1–1.5 м на плитку, на все грани, ×10.
- [ ] Рывок за ушко 5–10 кг, истирание кольцом за неделю.
- [ ] Брызги, нагрев в машине.
- [ ] Решить: задняя пластина, бампер стекла, покрытие.

### 8. Вариант B: своя плата

- [ ] Схема:
  - модуль nRF52840, BQ25180, TPS7A02, TPS22916;
  - LIS2DW12, T5838, датчик света;
  - USB-C с CC-резисторами и TVS;
  - площадки SWD;
  - экран по SPI.
- [ ] Разводка с учётом антенны.
- [ ] Ввод в эксплуатацию, перенос драйверов, загрузчик для обновлений по USB.
- [ ] Замеры: в темноте ≤20 мкА, с лицом ≤1.5–2 мА; тест разряда.

### 9. Надёжность и полировка

- [ ] 4 недели лица 24/7, затем осмотр на белом экране.
- [ ] 50+ циклов заряда, поведение на низком заряде.
- [ ] Сторожевой таймер, восстановление I2C, защита данных во flash.
- [ ] Обновление прошивки и паков эмоций по USB так, чтобы брелок нельзя было окирпичить.

## Риски

| Риск | Признак | Что делаем | Когда проверяем |
|---|---|---|---|
| Автономность ниже цели | Средний ток выше 2 мА | Контраст, VCOMH, кольца, ретро-режим, DARK, ячейка на 400 мА·ч | Этапы 2–3 |
| Выгорание экрана | Следы на белом экране | Дрейф, жесты, контраст ≤0x7F | Этап 9 |
| Ложные тапы при ходьбе | Реакции без причины | Аппаратный tap с окнами, записи с рюкзака | Этап 4 |
| Разброс модулей «SSD1306» | Сдвиг, мусор, не включается | Несколько продавцов, автоопределение контроллера | Этапы 0–2 |
| Хрупкий шлейф экрана | Полосы после ударов | Каптон и UV-клей, затем вариант C | Этапы 6–7 |
| Повреждение ячейки | Вздутие, проколы | Ячейка между платами или под пластиной, плата защиты, отсечка | Этапы 6–7 |
| Сон XIAO — сотни мкА | Ток DARK выше 50 мкА | Доработка питания XIAO или вариант B | Этап 3 |
| Лицо не видно на солнце | Не читается на улице | Максимальный контраст в ярком свете | Этап 6 |
| Ушко ломается | Трещины у отверстия | FR4 1.6 мм, запас материала, втулка, тест рывком | Этап 7 |

## Открытые решения

1. **Темнота:** гасить экран (по умолчанию, плюс 15–20 % автономности) или показывать «сонное лицо».
2. **Ячейка:** тонкая 402030 или ёмкая 602030 / 602035.
3. **Bluetooth:** нужен ли. Обновления и паки эмоций можно делать по USB, а радио добавляет ток и сложность.
4. **Задняя сторона:** открытая плата или пластина с артом (B+).
