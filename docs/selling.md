## Лицензия и чужой код

- **Лицензия проекта.** Код, плата и корпус открыты только для некоммерческого использования. Продаёт не правообладатель — нужна коммерческая лицензия ([COMMERCIAL.md](../COMMERCIAL.md)). Название, логотип и образ персонажа в неё не входят.
- **Надписи на экране.** Брелок показывает OLERAST: загрузка «OLERAST LINK» и логотип заставки на зарядке. Можно ли их оставить, оговаривается в лицензии.
- **Чужой код в прошивке** — его лицензии разрешают продажу, но просят сохранить уведомления. В прошивку брелока входит:

  | Что | Лицензия | Что сделать |
  |---|---|---|
  | Ядро Arduino для nRF52 (Adafruit), библиотеки Wire, SPI и PDM | LGPL 2.1 | текст лицензии — в памятке или по ссылке из неё. Исходники именно проданной прошивки — по ссылке на метку вашей сборки ([шаг 4](#свои-usb-vid-и-pid)) или по запросу покупателя: по ним он может пересобрать прошивку |
  | Bluefruit52Lib, TinyUSB, FreeRTOS, Adafruit LittleFS и InternalFileSystem, Adafruit nRFCrypto, загрузчик Adafruit nRF52 | MIT | уведомление об авторских правах и текст лицензии — в памятке или по ссылке из неё |
  | littlefs (Arm), nrfx (Nordic) | BSD-3-Clause | то же: уведомление и текст лицензии в документации к изделию |
  | CryptoCell CC310 (Arm, внутри nRFCrypto) | ARM Object Code and Header Files License | то же: уведомление и отказ от гарантий в документации к изделию |
  | SoftDevice S140 (Nordic) | лицензия Nordic | только в изделиях на чипах Nordic — модуль MDBT50Q на nRF52840, условие выполнено |

- **Где взять тексты.** В папке ядра nRF52 у PlatformIO (`~/.platformio/packages/framework-arduinoadafruitnrf52`): `LICENSE` в корне (LGPL), `libraries/Bluefruit52Lib/LICENSE`, `libraries/Adafruit_TinyUSB_Arduino/LICENSE`, `libraries/Adafruit_nRFCrypto/LICENSE` и `libraries/Adafruit_nRFCrypto/src/nrf_cc310/license.txt`, `libraries/Adafruit_LittleFS/src/littlefs/LICENSE.md`, `cores/nRF5/nordic/nrfx/LICENSE`, `cores/nRF5/freertos/License/license.txt`. У Wire, SPI, PDM, LittleFS и InternalFileSystem уведомление — в начале их файлов `.h`. У загрузчика — `LICENSE` в репозитории Adafruit_nRF52_Bootloader. Соберите всё в один файл уведомлений, выложите рядом с исходниками и впишите ссылку в памятку ([раздел «Открытый код»](user-guide.md#открытый-код)).

## Свои USB VID и PID

Сейчас брелок показывается компьютеру под номерами Adafruit: прошивка — 239A:810B, загрузчик — 239A:010B. Для прототипа это нормально, для продажи нужны свои. Готовые файлы в `firmware/release/` собраны с этими номерами и с Company ID 0xFFFF: они только для прототипов. Брелоки на продажу прошивают своей сборкой — и на заводе, и при обновлениях.

**Где взять:**
- **PID у компании, которая официально раздаёт PID под своим VID** (сублицензия). Обычно это самый дешёвый путь для малой партии.
- **Свой VID у USB-IF** — платный взнос, цену смотрите на usb.org. Под ним — сколько угодно своих PID.
- **pid.codes** раздаёт PID бесплатно, но только проектам под открытой лицензией (OSI). У этого проекта лицензия некоммерческая с платной коммерческой, поэтому он, скорее всего, не подходит.

**Что поменять** — это прошивка и загрузчик, плата та же:
1. `firmware/platformio.ini`, раздел `[sale]`: `usb_vid` и `usb_pid` — номера прошивки, `usb_pid_boot` — PID загрузчика, `ble_company` — ваш Company ID ([Bluetooth](#bluetooth)). Других мест для номеров прошивки нет: `firmware/tools/sale_ids.py` сам подставляет их в сборку.
2. `firmware/bootloader/emotion_keychain_revb/board.h`: `USB_DESC_VID`, `USB_DESC_UF2_PID`, `USB_DESC_CDC_ONLY_PID` — те же VID и PID загрузчика, что в `[sale]`.
3. Пересобрать загрузчик ([как](../firmware/bootloader/README.md#как-пересобрать)) и положить новый `.hex` вместо того, имя которого записано в `firmware/tools/uf2.py` (`BOOTLOADER_HEX`).
4. Закоммитить правки и поставить метку (например, `git tag sale-1.0`), иначе версия прошивки будет `-dirty`. Отправьте коммит и метку на GitHub (`git push` и `git push origin sale-1.0`): ссылка на метку — исходники проданной прошивки, их требует LGPL ([выше](#лицензия-и-чужой-код)).
5. Пересобрать прошивку: `cd firmware && pio run -e keychain`. В начале сборки — строка «Номера: USB 0x…:0x… (загрузчик 0x…:0x…), Company ID 0x…»: сверьте её со своими. Новый `firmware/.pio/build/keychain/firmware-factory.hex` уже с новым загрузчиком; для обновлений проданных брелоков — `firmware.uf2` этой же сборки, не `keychain-revb.uf2` из `release/`. Сохраните оба файла вместе с меткой.
6. Записать его программатором или отдать заводу ([программатор](#программатор)). Загрузчик по USB не обновляется: брелоки, прошитые раньше, сохраняют старые номера, пока их не перепрошьют по SWD.

## Bluetooth

- **Свой Company ID.** В пакете встреч сейчас `0xFFFF` — номер для прототипов (`ble_company` в разделе `[sale]` файла `firmware/platformio.ini`; в движке — макрос `FACE_ADV_COMPANY`, по умолчанию 0xFFFF). Свой номер выдаёт Bluetooth SIG своим участникам. Брелоки с разными Company ID друг друга не узнают: все проданные должны выйти уже со своим ([пакет](encounters.md#рекламный-пакет)).
- **Регистрация продукта.** Изделие с Bluetooth, которое продают, регистрируют в Bluetooth SIG (Declaration ID). У модуля Raytac есть своя квалификация, на неё ссылаются, но взнос за регистрацию продукта платный — условия на bluetooth.com.

## Радио и ЭМС

- **Модуль сертифицирован.** MDBT50Q-1MV2 прошёл FCC, IC, CE, TELEC и другие испытания — список и номера в документации Raytac. Это упрощает испытания брелока, но не заменяет их: на готовое изделие продавец оформляет свои документы для своего рынка.
- **Примеры:**

  | Рынок | Что обычно нужно |
  |---|---|
  | ЕС | декларация соответствия по директиве RED 2014/53/EU, знак CE, RoHS; на изделии или упаковке — имя и адрес производителя, номер партии, предупреждения на языке покупателя (Регламент о безопасности товаров, GPSR). С 18.02.2027 — съёмная ячейка ([батарея](#батарея)) |
  | США | FCC Part 15 для всего изделия и надпись «Contains FCC ID: …» с номером модуля |
  | ЕАЭС | ТР ТС 020/2011 «Электромагнитная совместимость» и знак EAC; про радиомодуль уточните у органа по сертификации |

- **Чтобы сертификат модуля оставался в силе:** модуль и его антенна без переделок и без своих антенн, зона без меди под антенной как в rev B, металл у антенны — как можно дальше, как просит Raytac ([README платы](../hardware/rev-b/README.md#расстановка-по-блокам)). Поэтому в брелоках на продажу винты и гайки корпуса только нейлоновые. Стальной винт в 7.7 мм от зоны антенны — только после согласования с лабораторией, которая проверяет изделие.

## Батарея

- **Документы поставщика ячеек.** Берите ячейки только у продавца, который даёт отчёт об испытаниях UN38.3 (UN38.3 test summary), паспорт безопасности (SDS) и паспорт ячейки ([детали партии](#детали-партии)). Без UN38.3 и SDS брелоки не примут курьеры и авиапочта.
- **Пересылка.** Готовый брелок — это литий-ионный аккумулятор в оборудовании (UN3481), ячейка ≈0.6–0.9 Вт·ч. Правила — у перевозчика: упаковка, маркировка, уровень заряда (для авиа часто просят не больше 30 %).
- **Утилизация.** Действуют местные правила сбора батарей и электроники. В ЕС — регистрация производителя по WEEE и Регламенту о батареях (EU) 2023/1542, значок перечёркнутого бака на изделии или упаковке.
- **ЕС с 18.02.2027 — ячейку меняет сам покупатель** (Регламент (EU) 2023/1542, статья 11). Аккумулятор в изделии должен сниматься и заменяться покупателем обычными инструментами из магазина, без пайки, нагрева и растворителей, а к изделию прилагается инструкция по замене.
  - В rev B ячейка припаяна к площадкам BT1 и лежит под припаянным модулем экрана — требование не выполняется.
  - Поэтому rev B в ЕС можно продать только до 18.02.2027. Дата считается по каждому брелоку: продали напрямую покупателю — это и есть выпуск на рынок. Брелоки, оставшиеся на складе после этой даты, в ЕС уже не продать.
  - После — только rev C: ячейка на разъёме с ключом ([план](plan.md)), снимается без пайки и без снятия экрана, корпус на винтах. В памятке тогда — как заменить ячейку, а «Не разбирать» на упаковке и «не разбирайте» в памятке убрать.
  - Точные правила и исключения сверьте с текстом регламента и руководством Еврокомиссии к статье 11.
- **Ячейка — только с платой защиты.** Защиты от переполюсовки на плате нет ([железо](hardware.md#питание)).
- **Ячейка закрыта корпусом.** У разъёма USB-C её торец закрывает нижняя рамка ячейки, окна под вилку в ней нет ([корпус](../hardware/rev-b/case/README.md#слои-от-лица-к-обороту)). На первых собранных брелоках попробуйте щупом или проволокой Ø 1 мм через разъём USB-C: до ячейки не достать.

## Детали партии

- **Номер заказа на плате.** Плату видно сквозь прозрачный корпус. В заказе JLCPCB выберите «Order Number (Specify Position)»: номер ляжет на метку `JLCJLCJLCJLC` под ячейкой ([заказ](../hardware/rev-b/README.md#заказ-на-jlcpcb)).
- **Паспорт ячейки (datasheet).** Попросите его у продавца ячеек и сверьте:
  - максимальный ток заряда — не меньше 100 мА: брелок всегда заряжает током 100 мА (у 150 мА·ч это 0.7C). Если в паспорте «max charge 0.5C», ячейка 150 мА·ч (версия S) не подходит: 0.5C — это 75 мА. Ячейке 200 мА·ч хватает и 0.5C;
  - температура заряда — диапазон включает 0–45 °C (как обычно у Li-Po; как минимум 7–45 °C): брелок начинает заряд при 10–42 °C по датчику в процессоре и останавливает его ниже 7 °C и выше 45 °C;
  - напряжение заряда 4.2 В, плата защиты (PCM) есть.

  Паспорт храните вместе с UN38.3 и SDS.
- **Модули экрана — 0.96″ на SSD1306.** Прошивка брелока запускает экран как SSD1306 (подходит и SSD1315 — у него те же команды). Модули на SH1106 не годятся: лицо будет сдвинутым или с мусором у края. На SH1106 сделаны почти все модули 1.3″ (на плату они и не встают) и изредка 0.96″. До пайки проверьте по одному модулю от каждого продавца и из каждой партии на стенде ESP32 ([стенд](../firmware/README.md#стенд-на-esp32)): лицо ровное — подходит; ровное только после команды `h` — это SH1106, не берите.

## Мемные эмоции

Мемы нарисованы заново в стиле персонажа, оригинальные картинки не копируются ([движок](engine.md#мемы-и-права)). Но часть из них узнаваемо повторяет чужих персонажей, а у некоторых есть активные правообладатели. Перед продажей их стоит проверить у юриста, перерисовать или переименовать. На упаковке, на сайте и в рекламе мемные имена не используйте.

| Эмоция ([каталог](emotions.md)) | На что похожа | Риск |
|---|---|---|
| `troll_grin` «Тролль-ухмылка» | Trollface | **высокий**: правообладатель известен и требует лицензию — первым делом перерисовать или убрать |
| `rage` «FFFUUU», `me_gusta` «Ме густа», `poker_face` «Покерфейс», `not_bad` «Неплохо», `challenge_accepted` «Вызов принят» | лица из rage comics; «Not Bad» нарисован по фото реального человека | средний |
| `soy_scream` «Ору (сойджак)», `soy_wow` «Восторг сойджака», `smug_glasses` «Ну-ну (вояк в очках)», `chad_stare` «Сигма-взгляд», `npc` «NPC», `doomer` «Думер» | семейство Wojak | средний |
| `pog` «Пог!» | PogChamp — лицо реального человека | средний |
| `swab_cat` «Кот с ватной палочкой» | вирусное фото кота | низкий |
| `lenny` `( ͡° ͜ʖ ͡°)`, `disapproval` `ಠ_ಠ`, `shrug` `¯\_(ツ)_/¯`, `table_flip`, `unamused` `-_-`, `wtf` `o_O`, `money` `$_$` | текстовые смайлики | низкий |

Имена эмоций видны только в документации, симуляторах и коде — брелок их не показывает. Перерисовка — правка пресета в `engine/src/expressions.cpp`, как в шагах [«Как добавить эмоцию»](../README.md#как-добавить-эмоцию); после неё пересоберите каталог (`./build/facegen catalog docs/emotions.md`). Рисунок и русское имя (`.name`) меняйте свободно, а `id` — только до продажи первых брелоков: по нему в памяти брелока хранятся выигранные и подаренные эмоции.

Памятка покупателю ссылается на каталог эмоций (`docs/emotions.md`), а в нём видны эти имена. Переименуйте их и пересоберите каталог до того, как дадите покупателю ссылку, — или уберите из памятки ссылку на каталог и оставьте только лист эмоций (`docs/img/emotions_sheet.gif`).

## Программатор

- **J-Link EDU Mini — только для некоммерческих брелоков:** по лицензии SEGGER им нельзя прошивать устройства на продажу.
- **Для продажи:** J-Link BASE или BASE Compact (коммерческая лицензия, уровни по VTref) или прошивка на заводе — PCBWay «Firmware loading». Файл в обоих случаях — `firmware-factory.hex` вашей сборки со своими VID/PID и Company ID ([шаги выше](#свои-usb-vid-и-pid)). Файлы из `firmware/release/` — с номерами Adafruit 239A и Company ID 0xFFFF, они только для прототипов. Другие варианты и кабели — в [закупках](hardware.md#закупки-для-сборки).

## Возраст и предупреждения

- **Не для детей младше 14 лет:** мелкие детали (кольцо, винты, гайки), литиевый аккумулятор внутри. Это не игрушка: продавать брелок как игрушку для детей — значит попасть под правила безопасности игрушек (в ЕС — директива 2009/48/EC, в ЕАЭС — ТР ТС 008/2011), они намного строже.
- **На упаковке:** «Содержит литий-полимерный аккумулятор», «Не для детей младше 14 лет», «Не разбирать, не нагревать, не мочить», значок утилизации, ваше имя и контакт.
- **Не водонепроницаем.** Тесты на брызги ещё впереди ([план](plan.md)): не обещайте защиту от воды.
- **Время работы** в объявлениях и на упаковке пишите «по расчёту» или не пишите, пока нет своего теста разряда ([испытания](#испытания-до-первой-продажи)). Цифры памятки (11, 15 и 18 дней) — расчёт по симуляции.

## Памятка в коробке

- Положите в коробку [памятку владельцу](user-guide.md) — напечатанную или ссылкой с QR-кодом — и [карточку](user-guide.md#карточка-в-коробку).
- Обязательно для покупателя: заряжать в тепле, с мороза сначала согреть; после выключения на пустой ячейке зарядить в течение недели; вздутый брелок не заряжать.
- В раздел памятки «[Открытый код](user-guide.md#открытый-код)» впишите две ссылки: на файл уведомлений чужого кода и на исходники вашей метки ([лицензии](#лицензия-и-чужой-код)).
- Про ссылку на каталог эмоций — в [мемных эмоциях](#мемные-эмоции).

## Испытания до первой продажи

Один раз — на первых собранных брелоках, до того как продавать. Результаты (числа и что не прошло) запишите в [план](plan.md). Испытания могут изменить сборку: защиту шлейфа экрана, покрытие платы, бампер ([железо](hardware.md#детали-которые-важны-для-прочности)).

**Звон USB при горячем подключении.** По модели на плате при подключении USB напряжение на VBUS и VSYS на короткое время выше предела модуля 5.8 В ([почему](hardware.md#питание)). Для своих прототипов этот риск принят, для продажи замер обязателен.

- 2–3 платы после шага 1 сборки, пока точки C8 и TP2 открыты, и осциллограф от 50 МГц (можно в мастерской или у знакомых). Точки на плате, настройки и порядок — в [README платы](../hardware/rev-b/README.md#на-первых-платах).
- Кабель — самый короткий и толстый, какой найдёте: худший случай — короткий кабель USB-A — USB-C на 3 А. По 10 подключений от каждого источника: зарядник телефона с гнездом USB-A, порт компьютера, пауэрбанк и те зарядники и кабели, которые будете советовать покупателям.
- **Годится,** если во всех подключениях пик и на C8 (VBUS), и на TP2 (VSYS) не выше 5.8 В.
- **Не годится** — хоть раз выше 5.8 В. Тогда выберите одно:
  - найдите зарядник и кабель, с которыми замер проходит (обычно зарядник USB-C с кабелем C–C или кабель длиннее и тоньше), повторите с ними замер и советуйте покупателю только их — в [памятке](user-guide.md#зарядка), в таблице «Коротко» и на [карточке](user-guide.md#карточка-в-коробку);
  - или не продавайте до rev C с демпфером у разъёма ([план](plan.md)).

**Пилотная партия** — например, 5 брелоков, хотя бы по одному каждой версии, которую будете продавать:

| Испытание | Как | Годится, если |
|---|---|---|
| Падение | с 1–1.5 м на плитку, на каждую грань, всего 10 раз | корпус не треснул у винтов и ушка, ячейку не видно, лицо и кнопка работают |
| Рывок за ушко | груз или безмен 5–10 кг на кольце | у отверстия ушка нет трещин |
| Заряд на холоде | час в холодильнике (+4…6 °C), сразу USB и `sensors`; потом то же из морозилки | температура в `sensors` — в пределах 2 °C от термометра рядом; из морозилки консоль пишет «Заряд не идёт», светодиод ярко не горит |
| Пустая ячейка | разрядить до конца | брелок сам показывает LOW BATTERY и GOODNIGHT и гаснет; нажатие кнопки на миг показывает пустую батарею; после зарядки работает |
| Ток | PPK2 ([как мерить](power.md#как-мерить)) | выключенный — меньше 25 мкА, карман — не больше 0.3 мА, лицо на свету — не больше 2.7 мА |
| Время работы | полная ячейка, 16 ч лица на свету и 8 ч темноты в сутки, до выключения | записать дни у каждой версии; в памятке и объявлениях — эти дни вместо расчёта |
| Циклы заряда | 50 циклов: полный заряд, потом разряд до выключения с лицом на свету (у S около 2 суток на цикл). Это месяцы — начните на первом же собранном брелоке | ячейка не вздулась, крышка и дно не отходят, время работы заметно не упало |
| Неделя носки | на рюкзаке, с ключами | нет трещин, кнопка не нажимается сама, лицо без полос |

## Каждый брелок перед отправкой

- [ ] Прошивка — ваша сборка для продажи: `ver` в консоли отвечает «Прошивка <ваша метка>, плата rev B», без `-dirty` ([своя сборка](#свои-usb-vid-и-pid)).
- [ ] Датчики: `sensors` — первая строка начинается с «Ускорение:», а не «Акселерометр не отвечает»; во второй — «Свет: есть».
- [ ] Зарядка: на USB при комнатной температуре красный светодиод горит ярко. У полностью заряженной ячейки он только тлеет — это норма.
- [ ] Кнопка щёлкает в корпусе, удержание 3 с выключает, короткое нажатие включает.
- [ ] Вилка USB-C обычного кабеля входит до упора.
- [ ] Встреча с вашим контрольным брелоком на 1 м, оба на свету: обычно через 1–3 минуты, изредка до 5–7. С завода дуэли включены, поэтому, если на контрольном брелоке их не выключали, сцена у обоих — дуэль (DUEL, потом WIN! или LOST) и разговор шифром. Контрольный брелок встречает не больше 6 новых брелоков за 15 минут и делает не больше 16 дуэлей в сутки, дальше только здоровается: при проверке подряд пауза — не поломка.
- [ ] На 2–3 брелоках из каждой партии — заряд на холоде, как в [испытаниях](#испытания-до-первой-продажи).
- [ ] Заряд для отправки — по правилам перевозчика.
- [ ] Последним — заводское состояние: контрольный брелок выключите (удержание 3 с) или унесите дальше 5 м, затем по USB в консоли `factory yes`. Консоль печатает «Рост: день 0, опыт 0, имплант 0/11, открыто 44/139 эмоций, достижений 0/24», «Шагов 0, касаний 0, друзей 0, дуэлей 0/0; дуэли вкл, невидимка выкл» и «Заводское состояние записано»; брелок прощается (GOODNIGHT) и гаснет. Отключите USB — он выключен. Больше его не включайте: следующим включит покупатель. Сбрасываются рост, достижения, знакомые, тема, звук, дуэли, невидимка, яркость, день рождения, дата и часы; позывной и характер — от чипа, они не меняются. «Запись во флеш не удалась» — повторите команду.
